# SpecMatrix Pro — 25-Parameter Laptop Telemetry & Decision-Science Engine

🔗 **Live Application:** [https://jugmadeepsaikia1224.github.io/specmatrix-pro/](https://jugmadeepsaikia1224.github.io/specmatrix-pro/)

Overview
SpecMatrix Pro is a full-stack hardware telemetry and decision-science web application designed to eliminate cognitive overload when comparing laptops. Instead of presenting static, unstandardized spec tables, it evaluates laptops across **25 standardized hardware, thermal, connectivity, and ownership parameters** on a normalized 0–100 scale.

Key Product Features
- Dynamic Persona Weighting Engine: Recalculates overall and category pillar scores in real time across 5 user archetypes (*Balanced, Software/AI Dev, Gaming/3D, Content Creator, and Student/Ultraportable*).
- 25-Point Telemetry Matrix: Covers CPU, RAM, Storage, GPU, Display, Battery, OS, Build Quality, Weight, Cooling System, Ports, Wireless, Keyboard/Touchpad, Webcam/Mic, Audio, Upgradeability, Security, Warranty, Software Support, Price/Value, Repairability, Benchmarks, Color Accuracy, Power Efficiency, and Additional Features.
- Cloud Database & AI Ingestion: Synchronizes laptop profiles and head-to-head comparison snapshots in real time via **Firebase Cloud Firestore** and supports structured Gemini API specification extraction.
- Visual Trade-Off Analytics: Features a 6-axis SVG radar chart, category winner badges, and a custom laptop heuristic simulator.
